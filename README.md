# Yu-Gi-Oh! LP Tracker · Cipher

Contador profesional de puntos de vida (*Life Points*) y compañero de duelos optimizado para dispositivos móviles y sistemas embebidos, desarrollado con **Python y Kivy**.

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/T4T629IUEU)

---

## 🛠️ Características Principales
* **Interfaz Dual Frente a Frente:** Marcadores independientes de 8,000 LP con opción de rotación independiente a 180° (botones y áreas táctiles totalmente sincronizados).
* **Modalidades de Duelo:** Soporte para Duelo Único (A 1 victoria) y formato de Torneo *Match / Mejor de 3* (A 2 victorias).
* **Herramientas de Duelo Integradas:** Lanzador de dados D6, volado de moneda digital, contador de turnos y teclado numérico personalizado.
* **Ciencia de Datos del Duelo:** Gráficas visuales de barras estilo *Cipher BATNA* para comparar LP y Victorias en tiempo real, además de un historial detallado exportable a formato `.txt` y `.csv`.
* **Soporte Bilingüe:** Interfaz completa en Español e Inglés con cambio dinámico.
